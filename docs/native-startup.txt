Relay CRM — native local startup (B2B sales and support)

From the repository root, after dependencies are installed:
  python3 scripts/dev.py

The app runs at http://127.0.0.1:3007 and the real API at port 8010.
Sign up in the app to create your own company and owner account.
SQLite data persists in backend/erp.db. Keep a backup of this file.
Ctrl+C stops both processes. Customize ports with --port and --api-port.

First-time installation on a normal networked machine:
  python3.11 -m venv backend/.venv
  backend/.venv/bin/python -m pip install -r backend/requirements-local.txt
  cd frontend
  npm install
  cd ..
  python3 scripts/dev.py

Use Python 3.11 and a Node.js version supported by frontend/package.json.
CRM_PYTHON can point to an already prepared Python interpreter.
Install the dependencies before using an existing interpreter.

Optional demo account, explicitly enabled with your own password:
  DEMO_SEED=true DEMO_PASSWORD='choose-a-demo-password' python3 scripts/dev.py
Its email is owner@demo.local unless DEMO_EMAIL is set. This creates a labelled
demo company and fictional sample CRM records once; repeat starts preserve them.
Do not enable demo seed in a production environment.

No Gmail credentials are needed: Gmail/calendar sync is deferred.
Email remains an unsent draft workflow; a provider adapter is not implemented.
Local runtime uses SQLite and in-process CRM operations. It does not require
PostgreSQL, Redis or Docker. The earlier ERP Compose stack is a separate profile.

API tests run against the actual app and temporary SQLite files in process.
Start the command above in your terminal to use the browser interface.
